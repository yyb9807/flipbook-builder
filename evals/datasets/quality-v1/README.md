# quality-v1 fixed fixtures

Six cases run root → child → grandchild through the production agent prompts,
parsing and normalization. All `replay.json` responses were authored as controlled
test data. They are **not** outputs from a real model and are not a quality gold
standard. They exercise the evaluation workflow without credentials or network.

| Cases | Fixed material | Reviewer focus |
| --- | --- | --- |
| `water-cycle-zh/en` | Original short summaries with USGS primary-source anchors | Direction of state changes, invisible vapor versus liquid droplets, qualifications |
| `fictional-reservation-zh/en` | Original, explicitly fictional closed-world rules | 8 places per session, 12 hours from submission, 48 hours from issue, undefined policies |
| `shapes-zh/en` | One original three-shape PNG, reused in two languages | Correct labels and bounding boxes, visible evidence versus invented physical properties |

The image has **one independent visual scene**, not two. Its simple shapes do not
measure natural-image grounding or generated-illustration quality. The PNG and
its original generator are under the included MIT license. No image was copied
from a third party or generated by a model. The text and reviewer notes are
original contributor-authored summaries or fiction under the same license;
external links identify factual references, not copied articles or model-cited
sources. References were checked on 2026-10-19 and are not fetched during a run.

`fact_checks` and `forbidden_claims` are manual review anchors. Exact source
excerpts bind those anchors to the supplied material; finding their words in an
output does not establish factual correctness. Root-only coverage requirements
are distinct from facts that apply on any page **if mentioned**, so a deeper page
need not repeat the entire original brief. Review unexpected claims as well as
the listed anchors. `unknown_limits` records what the input cannot establish.

Each of the two `branch_steps` matches only a listed label, allowing normalized
case and whitespace. A missing branch blocks later stages. There is no unrelated
first-section fallback. A live model may therefore produce a useful page that
does not satisfy this deliberately fixed regression path; report that coverage
limit rather than silently changing the experiment.

Image boxes are normalized `(x, y, width, height)` with inclusive raster object
extents converted to half-open pixel bounds. Matching requires an allowed label
and IoU ≥ 0.5 using one-to-one assignment. This is a fixture-specific starting
threshold, not a universal visual quality standard. Duplicate predictions count
against precision and missing required regions count against recall.

Changing material, anchors, boxes, selectors or recordings changes the suite
digest. Create a new version when the intended benchmark changes; do not reuse a
past human review against different output. The small set is a regression aid,
not a statistically representative ranking of models.
