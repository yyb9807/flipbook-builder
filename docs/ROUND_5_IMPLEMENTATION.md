# 第五轮实施报告：AI知识正文与来源

2026-10-18。按[本轮计划](archive/ROUND_5_PLAN.md)先规划后实施。本文记录第五轮完成时的实测快照；后续仓库整理与当前复测入口见[验证说明](VERIFICATION.md)。

## 交付流程

主题创建和新子页现在产出可以直接阅读、编辑和继续展开的知识页：标题、导读、atlas/sequence版式、独立区块标题与解释正文。只需内容模型，创建与分支生成均有明确的可选插图开关；出图意图随操作冻结，不因刷新后丢失图片Key而改变。上传图片保持原有图像热点与坐标校正。

正文与可选插图使用同一次已有内容规划阶段，不增加来源检索或第二次正文调用。严格校验1–6区块、标题与导读长度、每块20–5000字正文；模型缺少有效正文会明确失败，不补虚构默认内容，不自动再付费调用。提示建议3–5个解释区块，不能只列探索关键词。后端自建ID，丢弃模型提供的热点、目标、参考链接、生成说明和核实声明。

新任务输入冻结`knowledge-v1`或`image-v1`；没有marker的旧任务继续旧分支。没有为旧任务无条件插入DBOS step。知识页即使配图也不额外定位；其`section`连接没有图像位置、尺寸或评分，`image`热点才有几何。这个区别避免把结构化页面导航伪装成模型定位，也减少不必要的视觉调用。

## 来源信息的含义

来源数据使用独立节点字段`content_metadata`，不为旧图片页强造空正文。生成说明由服务端根据真实输入类型和模型配置建立，编辑API不允许伪造或移除；不携带Key、provider endpoint、完整请求、文件名或任务内部信息。

作者可以填写最多12条参考资料：标题、可选网页地址与说明。作者资料不表示系统抓取过页面、核实过事实，或已经逐句支持正文。系统不采纳模型编造的引用。未附资料与尚未人工核对都是合法状态；旧作品不补造AI出处。人工核对是作者声明。正文、资料或热点文字变化使声明失效，纯选中/几何变化及同名重复保存保持原声明；旧页再生保留作者资料并重置核对状态。

编辑沿用页面草稿和保存按钮；无效链接就地提示、阻止保存但保留草稿。参考地址只允许无凭据的绝对HTTP(S)，前后端均校验协议、authority、长度和控制字符。阅读端再次过滤，使用React文本或安全DOM及`noopener noreferrer`，不执行资料文字。预览、JSON、ZIP和独立HTML沿用同一份公开字段白名单。

## 关系、保存与兼容

生成提交在短事务中保存正文、来源和section连接，回填真实hotspot_id。子页提交同时写父连接、父scene目标与子节点。服务端手动新增区块也原子建立连接，规范API响应回填前端，避免保存后继续用虚拟ID。拒绝跨页引用、重复连接、模型指定目标以及直接删除已有子页的区块。知识页不能通过图片热点接口添加无法显示的假坐标，必须添加正文区块。

已有热点或正文的整页再生继续409，防止覆盖作者内容和关系。符合条件的旧空白页可再生为知识页，页面ID保持，失败/取消保留原内容。来源只读保护与已有草稿、workspace revision、任务锁、凭据显式恢复和未知收费确认共同工作；未扩大为任意跨版本迁移或多worker保证。

## 验收与发现

完整浏览器步骤见[浏览器记录](ROUND_5_BROWSER_ACCEPTANCE.md)。实际完成仅内容Key创建、生成中刷新、正文编辑、资料增补/危险链接阻止、核对失效与草稿刷新、手动新增服务端区块、两层子页、三层阅读路径、预览、ZIP/JSON下载；另覆盖原图片输入、英文390px布局、可选插图失败保留正文、无效正文明确失败与旧本地作品。

本轮没有把数据检查当成播放器启动检查。首次下载的ZIP内容和关系正确，但开发环境播放器实际无法启动：嵌套Vite构建使用宿主development JSX，而React运行时被定义为production。已固定嵌套构建的生产JSX设置，不改变宿主NODE_ENV，新增`npm run verify:player`在两个独立宿主环境真实构建并用JSDOM检查启动、三层往返、正文、来源及核对状态。浏览器第二遍必须重新导出实际ZIP后打开确认，不能仅替换测试目录里的player.js。

[独立代码审查](ROUND_5_CODE_REVIEW.md)发现图片热点改名后核对未失效；修复同时覆盖服务端、当前节点、未保存草稿和保存响应。进一步用跨热点逆序、同tick、后续明确资料保存及失败重试回归，防止旧响应复活已失效的声明或覆盖新资料。第一批界面检查还修复英文首页示例的来源说明未传locale。所有修复集中完成后只做一次浏览器确认，不进行循环视觉微调。
