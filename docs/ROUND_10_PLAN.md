# 第十轮计划：模型无关的质量约束与独立保留集

制定于 2026-10-19，实施前基线 `cd39498`，分支 `codex/provider-neutral-quality`。按用户补充“现在不需要放具体的模型”，本轮不预置、绑定或筛选具体模型，不执行真实模型推理。此前仅进行公开资料核对和下载准备；已停止下载、删除本轮临时权重缓存，并撤回新增模型运行器适配。既有第九轮历史工具与测量保留。

## 实施范围与验收边界

先冻结独立保留集与评估合约，再依据第九轮已经记录的正文、定位、语言和跨页问题，实施模型无关的可选修订。保留用户自备兼容服务的配置方式，不把模型名称、厂商、权重或下载流程加进产品，也不按模型 ID 猜测能力或输出格式。

本轮通过离线回放、受控 HTTP 和真实产品流程验证合约、状态和恢复；这不能证明任何真实模型的质量提升。Agent 评审、人工评审和受控校准分别记录；未发生的真实质量评审保持未审，实验默认关闭。后续用户选择模型后，可显式使用同一评估入口进行真实验证。

## 评估与恢复合约

- 评估配置显式保存 `legacy-v1`、`grounded-v2` 和新增实验修订；CLI 默认对齐生产原行为。修订、生产源码、评估器、素材、供应商和额度均绑定恢复身份；变化时在任何调用或检查点写入前拒绝恢复。
- 图像保留上限 `max_image_hotspots` 默认 3，显式可配置 1–12；同时进入运行/恢复身份、policy、项目设置和过滤。需要四个以上目标的实验可明确传 5，与产品对应设置一致，不按真值数量自动推导，不后验修框。
- 原始输出、归一化结果和诊断分别保存。分支路径不同仍标记不可直接比较，不给整体分差或优胜模型。精确引文只能证明证据位置，不能自动证明语义正确；Agent 不得冒充人工。
- 保留原调用一次、显式额度、未知结果停止和不自动重试规则。默认不读部署 Key、`.env` 或其他产品凭据。第九轮历史结果不改写。

## 内容与热点优化

新增明确可选的 `focused-v3`，保持默认和 `grounded-v2` 的请求字节。根据已记录问题，缩短并明确语言要求，允许较少但实质充分的区块，保护素材中的数值、事件起算点、例外及未知事项；子页围绕所选问题增加机制、区别或限制，不能靠重复父页和补造个案规则填满版面。生成上下文仍区分原始文字、模型页面和已覆盖主题，并在入队时冻结。

图片使用显式、与供应商无关的坐标协议：`bbox_2d=[left,top,right,bottom]`，0–1000 相对坐标。只在 `focused-v3` 中验证并转换为现有 0–1 左上角加宽高；非法、倒置、越界、非有限框拒绝，不猜格式、不截到真值、不补另一次生成请求。旧修订继续原坐标合约。协议与原始诊断随修订记录，不按模型名称分支。

原有回放仍保留原字节；新协议的离线回放可将作者编写的旧 xywh 录制等价编码为 bbox_2d，明确记录为受控夹具适配，不使用真值框或事实答案，也不改真实模型响应。适配规则在查看保留集前冻结；实际调用没有输出修复或重试。

任务在入队时冻结修订、来源与上下文，恢复不重读后来的页面或服务器配置。保留 DBOS 名称、步骤顺序、旧 markerless 兼容和内容解析要求。默认不启用未经真实验证的实验。
