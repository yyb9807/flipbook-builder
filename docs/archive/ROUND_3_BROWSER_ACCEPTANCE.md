## 环境与方法

真实 React 开发界面 `http://localhost:5173`，正式 FastAPI/Agent/DBOS、真实隔离 Postgres 和本地 HTTP 假供应商。通过浏览器实际点击界面，未用隐藏 store、页面脚本写入或 HTTP 请求代替按钮。只使用合成测试凭据，未勾选「在此浏览器记住密钥」，未调用付费服务。

测试进程在准备恢复作品时已实际重启，规划结果保存在业务 attempt 中，出图阶段等待临时凭据。浏览器刷新后仍找到同一个任务；配置地址和模型不一致时，恢复按钮禁用。进入模型设置，填写与原任务一致的本地服务、模型和临时测试 Key，保存后返回原作品，再明确点击「使用当前设置恢复」。

## 旧子页流程结果

| 界面路径 | 实际结果 |
| --- | --- |
| 作品库打开 → 刷新 | 同一任务仍显示「需要重新提供凭据」，原根页保留，编辑按钮锁定 |

| 未知出图结果 → 重新调用 | 弹窗说明可能再次计费，默认焦点为「暂不重试」；明确确认后完成并新增页面 |
| 未知出图结果 → 取消任务 | 状态变为「任务已取消」，仍为原来的 1 页，编辑解锁，可再次选择未完成分支 |
