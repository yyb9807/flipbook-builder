# 第三轮浏览器流程验收

> 历史记录（2026-10-18）。本文保留当时状态；当前实现与可运行命令见[文档导航](../README.md)和[验证说明](../VERIFICATION.md)。旧 PoC / 36 场景 CLI 已退役。

2026-10-18。使用 CUA 实际操作浏览器界面；后端为正式 FastAPI、DBOS 与独立真实 Postgres，模型网络使用本地 HTTP 假供应商，未调用付费模型。测试准备脚本只生成隔离作品与故障状态；按钮操作未写入隐藏 store，也未通过 API 代替用户作出恢复、确认或取消决策。

## 子页流程：5 项

1. 打开待凭据任务，刷新并找回同一任务；到设置填写显式临时配置，点击恢复后完成，两页可编辑、保存、预览及导出。
2. 图片结果未知时选择保留文字，任务成功并显示缺少插图提示，两页保留。
3. 图片结果未知时点击 retry，在收费确认弹窗中明确确认，任务成功。首次同假内容命中了缓存，因此补第 5 项验证实际新外呼。
4. 图片结果未知时明确取消，任务终态为 cancelled，项目仍只有原页。
5. 唯一提示词的未知图片任务经界面确认 retry 后，假供应商内存记录的图片调用从 **1 增至 2**，两页成功保存。

对应真实数据库、尝试记录与下载 ZIP 扫描：[round3-browser.json](evidence/round3-browser.json)。恢复后的编辑器（当时本机截图/评审缓存，不随仓库发布）、收费确认（当时本机截图/评审缓存，不随仓库发布）、实际新外呼成功（当时本机截图/评审缓存，不随仓库发布）。

## 根页与单页再生：6 项

1. 打开尚无根节点的分析任务，刷新后保留任务界面；填写原模型配置并显式提供 Key，完成并原子切到新根页。
2. 打开待凭据的再生任务，显式恢复后更新同一个节点，项目仍为一页。
3. 再生图片结果未知时界面不提供 accept；明确取消后原标题、说明和图片保留。
4. 在该页面直接点击再生按钮创建新任务，完成后仍使用同一个节点 ID，并更新内容和图片。
5. 从创建表单实际提交文字主题，定位阶段刷新；任务继续，最终保存一页。假模型故意返回相同封面提示词，本项复用了已存在的图片缓存。
6. 从创建表单实际上传 600×400 PNG（2,456 字节）和「图形、空间关系」关键词，成功保存一页、两个热点；完成后刷新无需重新选择 File。预览及 ZIP 下载成功。

对应任务、文件原始及规范化 SHA256、关键词、数据库、外呼计数与 ZIP 扫描：[round3-browser-pages.json](evidence/round3-browser-pages.json)。空根页刷新（当时本机截图/评审缓存，不随仓库发布）、根页恢复（当时本机截图/评审缓存，不随仓库发布）、再生完成（当时本机截图/评审缓存，不随仓库发布）、再生取消（当时本机截图/评审缓存，不随仓库发布）、表单主题结果（当时本机截图/评审缓存，不随仓库发布）、上传图片结果（当时本机截图/评审缓存，不随仓库发布）、图片阅读预览（当时本机截图/评审缓存，不随仓库发布）。

上传图片只执行一次视觉分析，复用内联热点，不额外调用生图或定位。下载的图片作品 ZIP 为 70,410 字节，包含 HTML、共享播放器、CSS、作品 JSON、说明和一张 600×400 PNG，全部解压内容没有假 Key。两个浏览器数据库的逻辑字段、检查点/Base64 候选、原始关系文件、SQL dump、工作日志及资产均通过临时凭据扫描；具体数量保留在机器证据中。浏览器 demo 已正常停止并清理独立数据库。

## 验证边界

以上 **11 项是实际界面操作**，与自动测试和真实进程故障套件分别记录。它们不代表真实模型的内容质量、真实收费或所有设备组合已验证。ZIP 内容和实际下载已验证；真实浏览器双击 `file://` 的离线运行仍受工具限制，未将其计入本轮完成项。

正式 nginx/Postgres 构建另有 [18 项 HTTP 冒烟证据](evidence/round3-postgres-stack.json)，覆盖新分析与再生入口，以及旧 `/analyze` 的 202 快照适配。旧 200 SSE 分支仍被验证脚本识别，但本轮正式后端不再返回该格式。
