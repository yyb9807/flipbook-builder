## 结果与定位

产品主线已收敛为「免账号、自托管、可校正、可离线导出的视觉知识工作台」。保留 React/Vite、FastAPI、Postgres 和树状节点，不为改界面更换整套技术栈。

本轮完成一条无需模型 Key 的完整创作流程：工作台体验真实示例 → 明确创建自己的副本 → 编辑页面和分支 → 保存 → 预览 → 导出。教师、内容创作者与知识整理者是当前设计假设，尚无访谈或使用数据证明。

没有登录、注册、用户角色代码需要删除，也没有新增账号体系。服务器作品仍属于同一受信任实例；浏览地址不是权限隔离或不可变的公共出版物。

## 业务流程和 UX/UI

- **工作台**：创建入口、可直接体验的水循环示例与作品库形成任务顺序。浏览示例不自动添加项目，明确点击「创建我的副本」才进入本地创作。无后端、无 Key 也可使用这条流程。
- **本地创作**：支持主题知识页、可选本地图片、手工热点及分支。图片限制 2 MB，避免将大图直接塞满浏览器存储；本地数据清理边界在界面和 README 中说明。
- **编辑器**：桌面目录、画布、检查器三列；手机在画布/页面/热点/内容之间切换。内容优先的矿物白、深墨与海绿工具系统替换旧装饰样式。
- **内容草稿**：标题、说明、版式和内容区块可修改；按项目/页面持久保存未提交草稿。切面板、切页面、进入设置或刷新仍保留，顶部保存按钮和项目/页面标记同步反映未保存状态。保存前不将旧版本当成预览或导出结果。
- **热点与导航**：图片按自然比例完整显示，热点与图像共用坐标框；拖动仅预览，结束提交一次；支持键盘移动和取消。页面路径与分支返回使用真实祖先关系，共享只读浏览不覆盖编辑 store。
- **模型设置**：测试当前草稿而不自动保存；准确说明请求转发、测试成本和服务能力边界。Key 默认仅在内存，明确选择记住才明文持久化；切换服务地址/供应商清除对应旧 Key。
- **交互与可访问性**：确认弹窗遵从当前按钮焦点的 Enter 行为，支持 Escape、焦点约束与恢复；菜单支持键盘；图标有名称，焦点可见。应用文档语言跟随中文/英文切换，状态反馈有语义。

设计规则见 [DESIGN.md](../../DESIGN.md)。实际截图：桌面编辑器（当时本机截图/评审缓存，不随仓库发布）、工作台（当时本机截图/评审缓存，不随仓库发布）、移动端内容编辑（当时本机截图/评审缓存，不随仓库发布）。

## 架构、数据和生成

1. 新增可选、版本化 `SceneDocument v1`，支持分项图鉴与过程说明两种结构化页面。文字使用 DOM，已有图片节点兼容。后端校验字段、长度、唯一 ID 与热点/页面关联归属；数据库字段变更可重复执行。
2. `SceneRenderer` / `ProjectViewer` 由编辑器、预览、只读浏览和新离线播放器复用。离线包含经典脚本、样式、项目快照和图片；快照用白名单提取内容，不包含模型配置、Key 或未保存草稿。后端旧 ZIP 导出保留兼容降级展示。
3. 删除固定 2×2 热点和统一假评分。上传图复用真实图像分析坐标；生成图对实际图片再定位。定位失败或坐标非法时保留内容、返回空热点与警告，允许手工补充；缺失分数为 `null`。
4. 子页逐页事务提交，部分失败仍保留成功页面并标记可重试项。已有热点的页面暂禁整页换图，防止破坏坐标和链接。
5. 前端同一项目的写入串行；生成与待保存内容互斥，旧异步请求不能覆盖新打开的项目。服务器保存失败会保留本地恢复副本和重试入口。
6. DBOS 持久任务采用独立原型验证，**未接入生产生成路由**。真实子进程强杀、重启、凭据重新提供、幂等、取消和结果不确定窗口已有证据；详见[原型报告](DURABLE_JOBS_POC.md)。生产生成目前仍依赖进程与连接生命周期。

本轮结构化知识页主要通过手动创作与示例落地。AI 直接生成结构化 PageSpec、来源引用、真正参考图编辑、能力声明和不可变出版版本仍属下一阶段。

## 安全和开源基础

- 供应商地址、模型、Key 按组选择，任意客户端地址不能继承部署者密钥；普通 CRUD、编辑、预览和导出请求不携带模型凭据。
- 服务端实际解码、校验和重编码图片，移除元数据，使用不可变文件名和目录包含检查；增加 20 MB 文件与 22 MB 请求体限制、像素限制、nosniff/CSP。
- 离线 HTML 的标题和数据采用上下文安全编码，补恶意结束标签回归。
- 热点更新、新建及结构化内容关联校验节点/项目归属，避免跨节点写入；批量更新事务化。
- Compose 的前端和数据库默认绑定 localhost，CORS 使用明确本机源，环境模板与忽略规则同步。
- README 中英文、前后端开发说明、贡献指南、SECURITY 和 CI 已补齐；MIT 许可保留。移除不再使用的样式/动画依赖，Docker 执行包含类型检查的正式构建。
