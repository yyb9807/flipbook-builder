# 第七轮计划：独立只读发布与固定作品快照

制定于 2026-10-19，实施前基线为 `c277eb5`。本轮先确定发布边界，再实施与验收；沿用现有阅读器和编辑器视觉体系。

## 产品与流程

1. 服务器作品提供「发布固定版本」，明确展示作品修订、页数、发布时间和公开链接。发布只保存当时已经保存的内容；草稿、失败/待保存写入、恢复和活动生成期间阻止发布并说明原因。
2. 同一个作品可以有多个固定版本，每次新发布生成新链接。已发布的正文、分支、图片和阅读器代码不可覆盖；后续编辑、页面恢复、删除原作品或升级编辑器都不改变旧版本。
3. 提供发布列表、打开/复制链接和撤下操作。撤下使链接不可再读取，但无法追回读者已经下载的内容；随机链接可被任何得到它的人访问，不代表访问控制或私密分享。
   实施检查补充：作品库提供全局发布记录，删除源作品后仍能查看及撤下已保留的发布；删除确认说明此行为。
4. 现有 `/v/{projectId}` 保留为「当前实例预览」，与固定版本清楚区分。本地作品继续使用完整离线 ZIP；本轮不上传浏览器作品或接受客户端 HTML/JavaScript。

## 实现与数据边界

- 编辑 API 在项目写锁和预期修订号校验下读取整棵树，拒绝活动任务、不完整/不一致的分支、缺失图片及外部图片抓取。通过严格白名单输出正文、来源和核对状态，不包含密钥、供应商配置、原始输入、任务或历史。
- 服务器从可信构建产物复制共享 React 阅读器。每份发布在 `data/publications/{id}` 保存独立 HTML、JSON、图片、JS/CSS。先在隐藏暂存目录完成校验与复制，再原子发布；错误不产生半成品公开目录。
- 不新增需要依赖源项目生命周期的发布数据库表。私有清单记录源项目、修订、操作 ID、时间、页数和内容摘要；文件锁串行同项目发布，幂等操作不会因网络重试重复发布。撤下保留私有幂等凭据，不能通过重试复活。
- Compose 增加独立阅读服务，只读挂载发布目录，不接数据库、AI 凭据、上传目录或编辑 API；仅提供白名单公开文件 GET/HEAD，关闭接口文档和目录浏览。读者链接使用配置的独立服务地址。
- 发布目录与源项目图片分开管理；删除源作品不删除发布文件。管理员备份需同时包含数据库、源图片和发布目录。本轮仍是单实例可信编辑环境，不增加账号或多人协作。

## 验收

- 后端真实 Postgres 与文件系统：整树白名单、分支/图片复制、修订冲突、活动任务、重复操作、并发、缺失资产、无半成品、撤下幂等、删除源作品不影响发布。
- 独立服务真实 HTTP：无编辑/配置/数据库依赖，路径穿越和私有清单不可读，GET/HEAD 可用、写请求拒绝；停止数据库与编辑 API 后仍能阅读三层作品和图片。
- 前端测试：发布状态与阻塞原因、列表/错误/重试、固定版本与当前实例文案、中英和移动布局、工作区切换后的迟到响应保护。
- 全量前后端测试、lint、类型和 production 构建、共享播放器构建与既有历史/持久任务/整栈回归。
- 实际浏览器：生成/编辑三层作品→发布 A→继续编辑/恢复→A 不变→发布 B→独立打开 A/B→删源后仍可读→撤下失效；桌面与 390px 手机检查，不使用付费模型调用。
- 桌面/手机视觉成批检查后进行一次修复确认；功能和安全边界失败继续修复。最终独立审查并更新当前文档和可复现证据。
