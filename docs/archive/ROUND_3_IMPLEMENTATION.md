## 结果与用户流程

根页文字分析、图片分析、子页生成和单页再生现在共用持久任务基础。任务拥有稳定操作 ID、数据库状态、可补发事件、显式供 Key 和取消入口。空根作品有独立任务页；根页提交后读取服务器完整项目并进入编辑器。前端不再用旧请求生命周期执行收费生成。

浏览器实际完成：旧子页打开/刷新/设置/恢复/预览/下载，未知结果的保文字、计费确认重试与取消；新根页空根刷新恢复、首页主题创建、文件选择和图片创建、再生恢复/取消/按钮重新提交，以及新作品预览和实际 ZIP 下载。[浏览器记录](ROUND_3_BROWSER_ACCEPTANCE.md)包含截图、实际任务 ID 和机器证据。

## 业务与数据边界

- 上传先校验真实图片、去元数据并保存不可变资产，再原子创建任务/事件/DBOS队列。原文件与规范化资产 hash 分开冻结；工作流只携带资产引用。已接收操作无需重传图片；应答丢失先按原 operation 查询，确实未接收时才重试原输入。
- 单页再生冻结旧页面、父上下文与设置，直到完成才原子替换同一节点。失败或取消保留旧内容与状态；有热点或结构化正文的页面409，避免损坏链接或正文。页面按钮已改为「重新生成页面」，说明会更新说明和插图。
- 同一作品的新活动任务互斥，写入使用 project → node → job 的统一锁顺序。旧版本不同节点上的多个活动子页任务可继续恢复，迁移不强制取消，也不新增会阻碍升级的作品级唯一索引。
- 临时凭据只在进程内。所有收费调用先记 intent，已知成果复用，未知成果暂停。根页未知出图可保文字，再生未知出图需取消保旧页或明确重试；不自动二次调用。未保存页面草稿独立保留，服务器刷新不会擦掉其他作品或新输入。
- 新增 `root-analysis-v1` / `regenerate-v1`。原 `children-v1` 步骤源文件与上一轮正式容器 SHA256 一致：`d6adadee7590dda392312ec94224f30232145ae5230e70aeb217220a1caf6fcd`。应用版本与原队列兼容；这不表示任意跨版本工作流迁移已经解决。

## 审查修复

资产校验原先早于 intent 检查：如果一次远端请求结果未知，同时图片丢失，重启会以本地失败结束任务并解除锁。修复后在同一事务中区分 started/completed/无调用：started 保持 `waiting_confirmation / recovery`，禁止 retry/accept并明确可能已计费，核实后取消才解锁；completed 复用已知结果，最终提交仍校验资产；无未确认调用才直接本地失败。[独立审查记录](ROUND_3_CODE_REVIEW.md)保留发现和修复证据。

## 接口迁移与运行限制

新建任务统一202 + snapshot；新接口和参数见 [backend/README](../../backend/README.md)。**旧 `/analyze` 和 `/regenerate` 地址也升级为202任务协议，不再分别返回SSE/同步终态节点**，旧客户端需迁移。旧子页 SSE 仍是持久执行器适配器，持久服务不可用时503，不退回非持久收费流程。

仍仅支持一个后端 worker/副本、免账号的受信任共享实例。浏览器图片 SHA256 需要 HTTPS 或 localhost。创建项目本身应答丢失可能留下无收费的空作品；没有为此新增全局幂等创建服务。浏览器 file:// 双击离线包仍受工具协议限制，本轮实际下载并检查ZIP内容，通过在线阅读模式验收播放器，不宣称补齐该协议环境。远端CI尚未执行。

下一轮可推进结构化知识页的AI生成与来源信息，以及独立只读发布快照；无需为了本轮可靠性引入多副本、用户系统或新数据库。
